德州扑克 · 玩法规则

一、游戏目标

每人发 2 张仅自己可见的底牌，与桌面陆续翻开的 5 张公共牌组合，比谁的 5 张最佳牌型最大。赢家（或平局分池）收走底池；过程中可随时弃牌退出本局。

二、座位、庄家与盲注

本桌为 6 人环桌：Lin / Mika / Ken / Ava / Ryu 五位电脑玩家，以及你（HERO）。每局有一个庄家按钮（D）顺时针轮转，决定盲注位置：

  • 小盲（SB）：庄家左手第一位，强制下注 $100。
  • 大盲（BB）：庄家左手第二位，强制下注 $200；大盲额即本局的最低下注额，也是最小加注增幅的起点（每次加注增幅至少一个 BB，若此前已有人加注则不得小于其增幅）。

座位徽章实时显示当前标识：D = 庄家按钮、SB = 小盲、BB = 大盲，其余为「—」；你的位置在昵称旁以小圆片显示当前是 D / SB / BB。

三、发牌与四轮下注

发牌与老虎机 / 百家乐 / 21 点共用同一条 H743 随机链，做无放回抽取：每张牌按 16 bit 拒绝采样取一个均匀整数（消除取模偏差）后从剩余牌堆取走一张，全程不使用浏览器随机数；若两源皆不可用，则取消本手并把已投入筹码原额退回，绝不使用本地随机兜底。先后进行：

  • 翻牌前（Preflop）：每人发 2 张底牌（SB / BB 已先投盲注）→ 开始第一轮下注；大盲在翻牌前最后行动，若此前无人加注，可选择过牌或加注。
  • 翻牌（Flop）：一次性翻开 3 张公共牌 → 第二轮下注。
  • 转牌（Turn）：再翻 1 张公共牌 → 第三轮下注。
  • 河牌（River）：再翻 1 张公共牌 → 第四轮下注。

行动顺序：翻牌前从大盲左侧（UTG）起顺时针；翻牌、转牌、河牌每轮从庄家左手第一位仍在局且可行动的玩家起顺时针。每轮在所有未弃牌玩家下注额持平且均已行动后结束——若有人加注，其余玩家需重新行动。若只剩一名未弃牌玩家，则直接收池结束本局。

四、玩家动作

  • 弃牌（Fold）：放弃本局，已投入筹码不退还。
  • 过牌（Check）：当前无人下注（无需跟注）时，选择不投入并把行动权交下家。
  • 跟注（Call）：投入与当前最高注齐平的金额。
  • 加注（Raise）：先跟平当前最高注，再加注；最小加注增幅为一个 BB，且不得小于上一次加注的增幅（本页引擎据此校验）。
  • 全下（All-in）：投入全部剩余筹码；不足时按现有筹码封顶，触发边池结算。

五、结算与边池

四轮结束进入摊牌：未弃牌者亮出底牌，从 2 张底牌与 5 张公共牌共 7 张中任取 5 张（可用 0、1 或 2 张底牌）组成最大牌型比大小；牌型相同则依次比较关键牌与踢脚，仍完全相同则平分底池（花色不分大小）。

当玩家筹码投入不一致时，按投入层级划分边池：仅参与该层级的玩家竞争对应底池，做到「跟多少、赢多少」。仅剩一人未弃牌时，直接收走整个底池（其余弃牌）。

六、牌型大小（由大到小）

  • 皇家同花顺 ＞ 同花顺 ＞ 四条 ＞ 葫芦 ＞ 同花 ＞ 顺子 ＞ 三条 ＞ 两对 ＞ 一对 ＞ 高牌（皇家同花顺即 A-K-Q-J-10 的同花顺，为最大牌型）。
  • 同花顺比最高牌点数；其余牌型先比类别，再依次比关键牌与踢脚。花色不分大小：牌型与全部比较牌都相同的两手牌平分底池。
  • A 可作最大（如 A-K-Q-J-10）也可作最小（A-2-3-4-5 为最小顺子）。

七、本页玩法与数据边界

本页接入 H743 随机链（在线 8765–8784 · 串口直供片上 TRNG；离线 8770 · 熵快照 + DRBG：以芯片采到的 4096 B 物理熵为种子喂 ChaCha20 DRBG，默认、不占串口；发牌按 16 bit 拒绝采样无放回抽取）与全局钱包（slot_credits / slot_card / slot_broke / slot_profit）；牌面沿用 assets/cards/ 下 CC0 图片。底池、本局已投与五位电脑座位的筹码属牌局内演示数据，不写入全局钱包；你的筹码即全局钱包余额，只有你真实下注与结算派彩才改动 slot_credits，并经 storage 事件与老虎机 / 百家乐 / 骰宝 / 21 点四页同步。战绩单独存 holdem_*。

八、对手 AI 与状态反馈

轮到 AI 对手时，会按其真实策略自动执行（依据牌力与底池赔率决定跟注 / 加注 / 弃牌 / 过牌 / 全下）；你（HERO）始终手动决策——轮到你时牌局暂停并高亮可用按钮（弃牌 / 过牌 / 跟注 / 加注 / 全下；无需跟注时显示「过牌」、需要跟注时显示「跟注」，二者互斥），由你点选后牌局才继续。一局结束后弹出结算弹窗，点击空白处或按空格关闭后自动发下一手，整桌持续运行。摊牌时弹出结算弹窗（赢=绿 / 输=红 / 平=金，与百家乐、21 点同一套视觉），显示谁赢得底池及你的净盈亏，持续显示直到点击空白处或按空格关闭。状态行显示接入源（在线 / 离线 / 端口）、检测中、不可用，以及钱包与卡内余额；异常（取数失败、数据异常、状态冲突、积分不足、破产补给）一律在扣款前拦截，失败不改动全局钱包，两源皆不可用则取消本次操作。
