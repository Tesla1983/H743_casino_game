玩法规则

游戏目标

投掷 三颗骰子，按你事先押注的注位判定是否命中：命中的注位按对应赔率派彩，未命中的注位本金不退还。目标是在一掷之内让所押注位尽可能多地命中。

骰子与点数

  • 每局投掷 三颗 六面骰，每颗点数 1–6；三颗合共为 3–18 点。
  • 奇偶：合共点数的单双（如 9 为单、10 为双）。
  • 豹子：三颗同点（如 4-4-4）；豹子会通杀大 / 小 / 单 / 双四类注位（详见结算）。

下注方式

先在筹码盘选好面额（5 / 25 / 100 / 500 / 1000），点击下方注位放注——可累加、可同时押多个注位，右键撤去该注位一注。每注位单注上限 5000、整局最低 5。点「投掷」时一次性扣除本局全部注额，投掷后按命中注位返还（含本金）。

「单点 1–6」押某一颗点数：每颗骰子出现该点数即计一次，出现 k 次赔 k 倍（1 次 1:1、2 次 2:1、3 次 3:1）。若所押点数恰好三颗同点，该单点注按 3 : 1 派彩；想以更高赔率博「三同」，需另押「围骰」。

开奖与结算

  • 投掷得出三颗骰子与合共点数、奇偶；系统逐注判定命中。
  • 豹子通杀：出现三颗同点时，大 / 小 / 单 / 双 四类注位全部判负（无论和值落在哪一区间）；但「单点」（该点数出现 3 次 → 3:1）与「围骰」（30:1）仍照常派彩。
  • 多注同中：各类押注可同时命中，结算时逐注累加返还；返还额 = 本金 + 赔额（已含本金），未命中的注位本金不退还。
  • 随机源兜底：在线（H743 串口直供）/ 离线（熵快照 + DRBG）两源皆不可用时，本局不扣分、直接取消，已下的注原额保留。

庄家优势提示

不同押注的庄家优势不同：大 / 小 / 单 / 双最低（约 2.78%），单点次之（约 7.9%），围骰等高赔率注位风险更高。高赔率注位对应更高风险，请以赔付表为准、量力下注。
